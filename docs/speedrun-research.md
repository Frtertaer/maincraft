# Ресерч: автономный спидран Minecraft — техники и архитектура

Собрано из открытых проектов и спидран-гайдов. Назначение — план фаз для этапа "спидран" после чистого прохождения.

## Ключевой вывод: алмазы не нужны

Человеческий RSG-роут обходит алмазную фазу целиком. Наша лестница `wood→stone→iron→diamond→portal` — "казуальная". Спидран-роут:

```
wood → stone → iron (3 слитка: ведро; +меч/щит по возможности) →
bucket-портал (лавовое озеро + ведро воды, алмазная кирка НЕ нужна) →
nether: бастион (золото) + крепость (rods) → бартер → перлы →
overworld: 2 броска глаза → триангуляция → стронгхолд →
end: кровати → one-cycle дракон
```

Это убирает самую долгую и опасную фазу (поиск алмазов на y<16 с лавой).

## Техники по фазам

### Портал без алмазов (bucket portal)
- Нужно: 3 железа (ведро), вода + лавовое озеро, flint&steel (железо + кремень из гравия) или огненный заряд.
- Литой портал: ставим воду, льём лаву ведром по форме рамки — обсидиан образуется на месте, копать не надо.
- Альтернатива: разрушенный портал (ruined portal) — часто не хватает 2-4 обсидиана + есть золото/огниво в сундуке. Источники: подводные руины, сокровищницы.

### Незер — бартер вместо охоты на эндерменов
- Бартер: бросить золотой слиток взрослому пиглину, 6 сек инспекции, случайный дроп.
- Математика (1.16.1+): 2.18% шанс перлов на слиток, дроп 2-4 шт → статистически ~40-60 слитков (5-7 золотых блоков) на 12 перлов. Дисперсия высокая: бывает 20 слитков, бывает 80.
- Золото в бастионах (блоки → ×9 слитков каждый, копать железной киркой):
  - Treasure: 15-27 блоков — лучший;
  - Bridge: 8-15; Housing: 10-18; Stables: 5-10 — худший.
- Побочный лут бартера: Fire Resistance potion (1.74%) — жирный бонус для блейзов; обсидиан 8.71%; железные самородки.
- Пиглины враждебны без золотой брони — 1 любой золотой предмет = нейтралитет. Правило: перед незером 1 золотой шлем/ботинки.
- Опасности для бота: гасты, лава повсюду, вода в незере не работает (только зелья/шерсть? нет — вода испаряется).
- Наш плюс: mineflayer видит сущности пакетами — скан на скопление пиглинов = детектор бастиона без F3-pie-ray.

### Фортуна крепости — блейз-роды
- Ищем spawner-руму в крепости (скопление блейзов = детектор, как с пиглинами).
- 6-7 родов на 12+ глаз (блейз порошок ×2 на глаз).
- Fire res от бартера сильно упрощает файт. Без неё — щит + укрытие за стенами.

### Триангуляция стронгхолда
- Классика: 2 броска глаза с разных точек → пересечение линий. Для бота угол измеряется идеально (позиция+скорость сущности из пакетов) — ошибки нет, двух бросков достаточно детерминированно.
- Ninjabrain Bot (github Ninjabrain1/Ninjabrain-Bot): байесовская модель — кольца генерации стронгхолдов, снаппинг к чанку, сдвиг до ±7 чанков, "8,8 strat": глаз указывает на позицию (8,8) внутри центрального чанка портальной комнаты. Можно портировать их математику (triangulation.pdf в репо) — но нашему боту с идеальным углом хватит простого пересечения + поправки на (8,8).
- Глаз ломается с 20% шансом на бросок — запас ~3-4 глаза сверх 12.
- Копаем вниз в точке (8,8) предсказанного чанка.

### Энд — one-cycle дракона
- Кровати взрываются в Энде при попытке лечь. 4-7 взрывов убивают дракона за один perch (посадку на фонтан).
- Механика perch: шанс посадки 1/13 при всех кристаллах, растёт до 1/3 по мере уничтожения. Ждём у фонтана с севера/юга.
- Взрывы НЕ дают дракону досесть на верх фонтана (иначе перелёт после >50 урона).
- Нанести ~50 близко к концу, добить взрывом или заряженным топором. Криты не работают — не прыгать.
- **Наш плюс**: конвейер овца→шерсть→кровать уже построен для пропуска ночей — кровати это одновременно и оружие дракона. Фармим 5-6 кроватей перед входом в Энд.
- Кристаллы: лук+стрелы ИЛИ столбик к клетке и разбить рукой (часть в клетках из железных прутьев).

## Предлагаемая новая архитектура: Strategy DAG

Текущий phase ladder — линейный. Для спидрана и сложных этапов нужен **граф стратегий**:

- Узел = цель (напр. "12 перлов"); у узла несколько **способов** с оценкой применимости к текущему миру:
  - перлы: [бастион-бартер (нужно золото+бастион), охота на эндерменов (ночь+пустыня), деревня-клерик-трейд (редко)];
  - портал: [лавовое озеро+ведро, ruined portal добивка, алмазная кирка+обсидиан];
  - кровати для дракона: [шерсть овец, разграбление деревни, respawn-anchor как замена].
- Скаутер оценивает мир (биомы, структуры из памяти обзора, ресурсы) → выбирает живые рёбра → executor гонит выбранную цепочку; провал способа → fallback-ребро, а не тупик.
- Поверх — тот же reflex/instinct слой (норы/побеги/кровать ночью) не меняется.

Это и есть "ситуативность": один и тот же код проходит любой сид, потому что маршрут не зашит — он выбирается.

## Быстрые победы до полного DAG

1. Вести память структур при обзоре: уже пишем logSites/stash — добавить lavaPools, ruinedPortals, villages, bastions. Бесплатный скаутинг во время треков.
2. Bucket-портал шаг вместо алмазной фазы (нужен лишь bucket 3 iron + вода + лавовое озеро).
3. Nether entity-scan: скопление пиглинов→бастион, блейзов→крепость.
4. Триангуляция 2 броска + (8,8).
5. Bed-cycle: уже есть крафт кроватей — довести до 5-6 и бой на фонтане.
